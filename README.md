# Krishna_Great Portfolio V2

Glassmorphic, dark/neon-green portfolio with About / Skills / Projects / Contact tabs, animated circular hero, and project-category filters.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Check before publishing
- Confirm the `tel:` link is `tel:+918595739837` and the displayed phone number is correct.
- Some project cards link to the GitHub profile because exact repository URLs were not confirmed. Replace these with direct repo links.
- Confirm ADCA Gold Medal details (institution/year).
- Consider whether you want your phone number publicly visible.

## Publish with GitHub Pages
1. Create a repository such as `krishna-great-portfolio`.
2. Upload `index.html` and `README.md` to the root.
3. Go to Settings → Pages → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Open the published URL shown in GitHub Pages.
